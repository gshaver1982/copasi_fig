# copasi_figure

A small Tkinter-based GUI for turning COPASI text exports into publication-quality figures.

## Features

- Open COPASI `.txt`, `.tsv`, or `.csv` exports
- Auto-detect species columns such as:
  - `[A].Measured Value`
  - `[A].Fitted Value`
- Select species to plot
- Toggle measured/fitted traces
- Preview the table and figure
- Export to PDF, SVG, or PNG
